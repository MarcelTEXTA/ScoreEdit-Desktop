# TEXTA Score Edit

TEXTA Score Edit (ThevMarcelHosting project) is a music score editor optimized for Windows and Ubuntu, a non-profit software project. It is designed to provide a simpler experience for editing musical scores.

## Features

- Music score editor with editing assistance (not AI-powered);
- PDF export;
- Plug-ins (still in development);
- Management of `.score` files.
