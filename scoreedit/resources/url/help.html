TEXTA Score Edit Help

Editing a score

Choose a clef, time signature, and note value in the score toolbar, then click the staff to insert notes.

Use the sidebar to select, move, duplicate, split, or delete notes and to add accidentals or measures.

Select a note to use the pitch and octave controls. Use Options > Edit for undo, redo, and clipboard actions.

Files and output

Save scores as .score files. Use Print to print a score or export it as a PDF.

The MIDI editor imports and exports Standard MIDI Files. Click a cell to add a note, drag to set its length, and right-click to delete it.

The virtual keyboard adds notes to the main score. The text editor opens and saves plain-text lyrics.

Playback opens a temporary MIDI preview in the MIDI player associated with your operating system.

Preferences and plug-ins

Use Options > File > Preferences to change the theme, animation, default score folder, MIDI tempo, and note velocity.

Plug-ins are listed in the Plug-ins tab. Only install plug-ins from sources you trust.
